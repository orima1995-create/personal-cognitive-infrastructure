## 原則
1. 出典状態は `写真確認` / `注文通知確認` / `本人申告` / `公式確認` / `推測` / `未確認` を区別する。推測を実測へ昇格しない。
2. `購入済` / `配達通知のみ` / `検討` / `見送り` / `使用済` を混同しない。特に2026-11-07の初回外出は**予定であり、実施確認はまだない**。
3. GEARの追加購入サジェストは「困った現象 → 既存品で対処できるか → 適合性 → 購入候補」の順。購入の提案を所有扱いしない。
4. SPOTSのブログ利用例は法的許可と区別。日付・公式URL・未確認事項を保存し、訪問前に再確認。
5. TRIPSは1回につき短い事実記録でよい。実験や計測を義務化しない。体験と本人の感想が優先。
6. 個人の住所、交通定期経路、氏名、注文番号、店舗への私的連絡履歴などは公開リポジトリに保存しない。
7. 他ドメインの時計研究・SNS・PCIの既存ファイルへ自動転記しない。キャンプの記録が増えたらこの3ファイルを更新する。
